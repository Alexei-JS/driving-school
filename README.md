## 📌 О проекте

«Автошкола» — проект, призванный сделать процесс обучения понятнее,
а взаимодействие учеников и автошколы — удобнее.

Идея проекта — объединить информацию об обучении в одном месте
и помочь будущему водителю пройти путь от первого знакомства
с правилами дорожного движения до уверенности за рулём.

## 🎯 Цель

Создать простой и удобный инструмент для организации обучения,
в котором главное — доступность информации и комфорт пользователей.

## 🚧 Статус

Проект находится в разработке.
